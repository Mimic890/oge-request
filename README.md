# OGE Monitor Bot

Telegram-бот для мониторинга результатов ОГЭ на [ege-kostroma.ru](https://ege-kostroma.ru).

Каждые N минут проверяет сайт и уведомляет о изменениях. Каждый пользователь настраивает свой код участника через бота.

## Быстрый старт

### 1. Получите токен бота

Отправьте `/newbot` [@BotFather](https://t.me/BotFather), скопируйте токен.

### 2. Узнайте свой Telegram ID

Отправьте `/start` [@userinfobot](https://t.me/userinfobot).

### 3. Склонируйте и настройте

```bash
git clone https://github.com/YOU/oge-request.git
cd oge-request
cp .env.example .env
```

Отредактируйте `.env`:

```
TG_TOKEN=123456:ABC-DEF...
ADMIN_ID=123456789
MAX_USERS=0
CHECK_INTERVAL=600
```

| Переменная | Описание |
|---|---|
| `TG_TOKEN` | Токен бота от @BotFather |
| `ADMIN_ID` | Telegram ID администратора (0 = нет админа) |
| `MAX_USERS` | Лимит пользователей (0 = без лимита) |
| `CHECK_INTERVAL` | Интервал проверки в секундах (600 = 10 мин) |

### 4. Запустите

**Docker (рекомендуется):**

```bash
make docker
```

**Или напрямую:**

```bash
make run
```

## Команды бота

### Обычный пользователь

| Действие | Описание |
|---|---|
| `/start` | Запуск, главное меню |
| Настроить код | Ввести код участника XXXX-XXXX-XXXX |
| Проверить результаты | Мгновенная проверка на сайте |
| Мои результаты | Показать сохранённые данные |
| Отключить бота | Удалить код и прекратить проверки |

### Администратор (дополнительно)

| Действие | Описание |
|---|---|
| `/status` | Статус бота |
| Статус бота | Аптайм, кол-во пользователей, проверок, трафик, RAM |
| Пользователи | Список registered пользователей |
| Память | Подробная статистика памяти |

## Структура проекта

```
├── main.go           точка входа, конфигурация
├── bot.go            обработчики Telegram, меню
├── checker.go        запросы к сайту, парсинг HTML
├── checker_bg.go     фоновая проверка всех пользователей
├── storage.go        хранение данных (JSON)
├── admin_stats.go    статистика (трафик, RAM, посещения)
├── Dockerfile        multi-stage сборка
├── docker-compose.yml
├── .env.example
└── Makefile
```

## Остановка и очистка

```bash
make docker-stop
rm -rf data/
```
