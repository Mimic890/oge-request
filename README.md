# OGE Monitor Bot

Telegram-бот для мониторинга результатов ОГЭ на [ege-kostroma.ru](https://ege-kostroma.ru).

Каждый пользователь настраивает свой код участника и интервал проверки. Бот отслеживает изменения и уведомляет.

## Быстрый старт

### 1. Получите токен бота

Отправьте `/newbot` [@BotFather](https://t.me/BotFather), скопируйте токен.

### 2. Узнайте свой Telegram ID

Отправьте `/start` [@userinfobot](https://t.me/userinfobot).

### 3. Склонируйте и настройте

```bash
git clone https://github.com/Mimic890/oge-request.git
cd oge-request
cp .env.example .env
```

Отредактируйте `.env`:

```
TG_TOKEN=123456:ABC-DEF...
ADMIN_ID=123456789
MAX_USERS=0
MAX_RPS=2
```

| Переменная | Описание |
|---|---|
| `TG_TOKEN` | Токен бота от @BotFather |
| `ADMIN_ID` | Telegram ID администратора |
| `MAX_USERS` | Лимит пользователей (0 = без лимита) |
| `MAX_RPS` | Максимум запросов к сайту в секунду |

### 4. Запустите

**Docker (рекомендуется):**

```bash
make docker
```

**Или напрямую:**

```bash
make run
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск, главное меню |
| `/status` | Статус бота (только админ) |
| `/repo` | Ссылка на исходный код |

## Возможности

### Основные

- Мониторинг результатов ОГЭ в реальном времени
- Индивидуальный код участника для каждого пользователя
- Уведомления об изменениях результатов
- Просмотр сохранённых результатов

### Настройки уведомлений

- Включение/отключение уведомлений
- Выбор интервала проверки: 15, 30 или 60 минут
- Настройки хранятся индивидуально для каждого пользователя

### Автоматическая очистка

- Пользователи, неактивные более 2 месяцев, получают предупреждение
- Через 7 дней после предупреждения данные удаляются
- Пользователь не блокируется — можно начать заново через `/start`

### Администрирование

- Статус бота (аптайм, пользователи, трафик, RAM)
- Мониторинг доступности сайта
- Уведомление администратора при недоступности сайта
- Список пользователей с настройками

## Структура проекта

```
├── main.go           точка входа, конфигурация
├── bot.go            обработчики Telegram, меню, клавиатуры
├── messages.go       все тексты сообщений (легко редактировать)
├── checker.go        запросы к сайту, парсинг HTML
├── checker_bg.go     фоновая проверка всех пользователей
├── inactivity.go     очистка неактивных пользователей
├── storage.go        хранение данных (JSON)
├── admin_stats.go    статистика (трафик, RAM, посещения)
├── bot_test.go       тесты
├── Dockerfile        multi-stage сборка
├── docker-compose.yml
├── .env.example
└── Makefile
```
